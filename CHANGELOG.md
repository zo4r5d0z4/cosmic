# Changelog

## [1.0.0] - 2026-10-18

### Added
- Configuration manager with JSON persistence
- 12 built-in themes (Amethyst, Crimson, Ember, Gold, Forest, Mint, Ocean, Azure, Indigo, Slate, Graphite, Light)
- Custom theme import via `.cosmic-theme.json` files
- ScriptHub API client for ScriptBlox, RScripts, and RobloxScripts
- Multi-instance configuration support
- Auto-attach and auto-update settings
- Bookmark system for frequently used scripts
- Recent scripts history tracker
- sUNC mode configuration (full / partial)
- Output console toggle
- MIT License

### Changed
- Initial public release

### Security
- Built-in malicious script detection guards
- Privacy-first design with minimal data collection
